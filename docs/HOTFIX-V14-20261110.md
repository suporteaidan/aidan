# Aidan v14 TypeScript / ESLint hotfix (2026-11-10)

This patch addresses the 6 TypeScript errors across 5 files and the unresolved NFC-e import.
It keeps Expo SDK 54 dependency versions and the lockfile untouched.

## Fixed

- Synchronized API contracts with the current FastAPI backend (`TokenResponse`, `NfeImportResponse`, nullable optional phone).
- Included `src/api/services/nfe.ts` and its route mappings.
- Updated registration to omit an empty optional phone instead of passing `null`.
- Recognized two new Expo Router paths in builds where generated route types are stale (`/import-receipt`, `/forgot-password`); both routes are present.

## Apply

From `~/Projects` (while project is on your `dev` branch):

```bash
unzip -o ~/Downloads/aidan-v14-typecheck-hotfix-20261110.zip -d ~/Projects
cd ~/Projects/aidan
rm -rf .expo
npx expo start --clear --web
```

After the Expo startup refreshes generated route types, stop it with Ctrl+C and run:

```bash
npm run typecheck
npm run lint
npx expo-doctor
git status
```

No additional dependencies are added by this patch. Do not replace `package-lock.json` or `.env`.
If the NFC-e service still appears missing, run:

```bash
ls -l src/api/services/nfe.ts
grep -n 'TokenResponse' src/api/contracts.ts
```
